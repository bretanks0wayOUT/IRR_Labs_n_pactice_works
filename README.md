## Метод

Корпус (books.toscrape.com + синтетический корпус) приводится к нижнему регистру и токенизируется регулярным
выражением по латинским словам; токены короче 2 символов отбрасываются. Индексируется
объединённый текст `title + description + genre`. Инвертированный индекс — словарь
`термин -> множество doc_id`; документ входит в posting list термина ровно один раз.
Булев поиск: AND — пересечение posting lists, OR — объединение.

## Вывод

В ходе выполнения лабораторной работы был успешно реализован пайплайн полнотекстового поиска: подготовка корпуса, построение
инвертированного индекса и выполнение булевых запросов для варианта 10 (N=1500, min_len=2, оператор OR).
Эксперименты показали, что с ростом размера корпуса словарь растет сублинейно в соответствии с законом Хипса.
Увеличение min_len с 1 до 5 закономерно уменьшает размер словаря за счет отсечения коротких служебных слов и шума. 
Булев поиск с оператором OR возвращает больше документов, чем AND, объединяя выдачу по терминам запроса.
Использование инвертированного индекса обеспечило многократное ускорение поиска (в сотни и тысячи раз) по сравнению с полным перебором 
ценой затрат на первичное построение индекса.
